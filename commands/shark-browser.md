---
description: Open or focus the shared Shark Chrome window and check which sites are logged in
---

Use the `shark-sell` skill.

1. Run `npm run dev -- browser` from the Shark repo root to open/focus the shared Chrome.
2. If the user names a platform, run `npm run dev -- auth --platform <facebook|whatsapp|yad2>`
   so its tab opens for a one-time login, and tell them to log in there.
3. Never open a different browser or ask for passwords.
